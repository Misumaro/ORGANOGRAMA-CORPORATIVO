Projeto web para visualização de **Organograma Corporativo Avançado**, desenvolvido em **HTML, CSS e JavaScript puro (Vanilla JS)**, focado em **clareza hierárquica**, **visual corporativo profissional** e **interações animadas de alto nível**, sem uso de frameworks externos.

---

## 🚀 Demonstração

🔗 **GitHub Pages:**
https://misumaro.github.io/ORGANOGRAMA-CORPORATIVO/

---

## 🧩 Funcionalidades

* 📌 Visualização completa da estrutura hierárquica corporativa
* 🧱 Múltiplos níveis organizacionais (Diretoria, Gerência, Operação e Subáreas)
* ➕ Expansão e recolhimento interativo por diretoria
* 🎞️ Animações sequenciais de linhas e cards
* 🧠 Organização visual clara mesmo em estruturas extensas
* 🖼️ Suporte a logotipo institucional
* 🔍 Ajuste automático de escala para a tela (*fit-to-screen*)
* 🧭 Layout preparado para navegação ampla (scroll horizontal e vertical)
* 🎨 Sistema de cores temáticas por área/departamento
* ⚡ Projeto leve, performático e sem dependências externas

## 📁 Estrutura do Projeto

```bash
ORGANOGRAMA/
│
├── index.html          # Estrutura principal do organograma
│
├── css/
│   └── styles.css      # Estilos, layout, temas e animações
│
├── js/
│   ├── data.js         # Estrutura do organograma (JSON)
│   └── script.js       # Motor de renderização e interações
│
├── assets/
│   └── logo.png        # Logo institucional (opcional)
│
└── README.md
```

> 🔹 O projeto está organizado de forma modular, separando **HTML**, **CSS** e **JavaScript**, o que facilita a manutenção, leitura do código e evolução futura.

## 🧠 Conceito do Projeto

Este projeto foi desenvolvido para atender **estruturas corporativas complexas**, onde organogramas tradicionais não conseguem representar corretamente:

* Grandes operações
* Múltiplas áreas funcionais
* Subníveis operacionais extensos
* Estruturas híbridas (gestão + operação)

O foco está em **governança visual**, **leitura rápida** e **experiência do usuário**, mesmo com grande volume de informações.

## 📌 Como Usar

1. Clone o repositório:

   ```bash
   git clone https://github.com/seu-usuario/organograma.git
   ```

2. Abra o arquivo `index.html` no navegador

3. (Opcional) Substitua a logo em `assets/logo.png`

4. Para editar os cargos e nomes, abra o arquivo `js/data.js` e modifique o objeto JSON conforme a estrutura da sua empresa. O layout será gerado automaticamente.

---

## 🧩 Customização

* 🎨 Cores podem ser alteradas facilmente via `:root` no CSS
* 🧱 Novos níveis e departamentos podem ser adicionados facilmente alterando apenas o arquivo `js/data.js`.
* 🧠 Lógica de renderização recursiva no JavaScript que adapta o layout (CSS Flexbox) automaticamente.
* 🖼️ Logo opcional (oculta automaticamente se não existir)
